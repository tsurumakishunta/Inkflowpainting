# アプリケーション説明

**日本語** | [English](./README.en.md)

## 概要

Ink Flow Paintingは、水面に落とした墨が滲み、混ざり、流れていく様子をブラウザ上で楽しめる墨流しアプリケーションです。

あらかじめ作られた動画を再生するのではなく、ブラウザが水の流れと顔料の動きをリアルタイムで計算しています。

![墨流しの動作デモ](./assets/墨流し.gif)

## 操作モード

### 手描き

黒・朱・緑・蒼から色を選び、マウスまたはタッチ操作で墨を流します。筆幅、墨の濃さ、水流の強さを調整できます。

### 色うつろい

使用する色が一定時間ごとにランダムで選ばれ、次の色へ滑らかに変化します。急に色が切り替わらないため、複数の色が自然に混ざり合います。

### 墨流し

墨滴と、既存の墨を外側へ押し広げる「散らし」を自動的に加えます。滴下位置と間隔には揺らぎがあり、同じ模様を繰り返さないようになっています。

## マウス操作と水の流れ

- クリックまたはドラッグすると、新しい墨と水への勢いが加わります。
- クリックせずにマウスを動かすと、墨は追加されず、水流だけが変化します。
- マウスを速く動かすほど水流が強くなり、移動方向に沿って既存の墨が運ばれます。

何も描かれていない場所では水流そのものは見えませんが、近くへ墨が流れてくると、事前に作られた水の流れに沿って模様が変化します。

## 墨が滲む仕組み

画面の裏側には、水の方向と速さ、圧力、顔料の色と濃度を記録する複数の計算用マップがあります。GPUが毎フレーム、次の処理を繰り返します。

1. 水の渦を計算する
2. 水が一か所へ不自然に溜まらないよう圧力を補正する
3. 水流に沿って顔料を運ぶ
4. 周囲の顔料と少しずつ混ぜて滲ませる
5. 顔料を徐々に減衰させて薄くする
6. 和紙の色と粒状感を合成して画面へ描画する

顔料は、周囲の濃度を超えて勝手に増えない方法で拡散します。そのため、新しい墨が追加されたり、流れによって墨が集まったりしない限り、同じ場所が時間とともに不自然に濃くなることはありません。

## 補助機能

- 静止・再開
- 水面と墨の消去
- 現在の作品をPNG画像として保存
- キーボード操作による一時停止と消去

## 動作環境

本来の表現にはWebGL2へ対応したブラウザとGPUが必要です。Chrome、Edge、Firefoxなどの新しいバージョンを推奨します。
