# 水墨 — 水に、墨をほどく。

水面に落とした墨が滲み、混ざり、流れていく様子を描くインタラクティブなWebアプリです。

## できること

- 黒・朱・緑・蒼を選んで、マウスや指で水面へ描く
- 描く色がゆっくり移ろうランダム彩色
- 墨と散らしを自動で重ねる墨流し
- 筆幅、墨の濃さ、水流、墨を落とす間合いの調整
- 一時停止、水面のクリア、PNG保存

## 起動

Node.js 22.13以降で次を実行します。

```bash
npm install
npm run dev
```

配布用の確認は `npm run build`、自動テストは `npm test` です。
